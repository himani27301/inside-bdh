# Inside BDH

**Inside BDH** is an interactive educational artifact for the DataForge 2026 Pathway track. It lets a learner change an input sequence and inspect how the same independently trained toy Dragon Hatchling (BDH) checkpoint transforms a signed latent projection into a non-negative sparse state.

- **Public artifact:** https://inside-bdh-1.onrender.com
- **Public source:** https://github.com/himani27301/inside-bdh

## One-sentence claim

> BDH converts a signed latent projection into an input-dependent, non-negative sparse state; changing the input changes which latent units survive.

## Intended learner

Undergraduate / early-career ML learners who know vectors, neural-network layers, ReLU, and the basic idea of attention, but have not studied BDH.

## Learning objectives

After about 60 seconds, a learner should be able to:
1. identify `x_latent = x @ encoder` as the signed pre-activation state;
2. explain why `x_sparse = ReLU(x_latent)` is non-negative;
3. predict which values become zero after ReLU;
4. change the input and observe changes in activity and top latent units;
5. distinguish our toy-checkpoint measurements from published BDH results.

## What is live

- user text input and byte-level encoding;
- BDH forward pass using `bdh_trained.pt`;
- `x_latent`, `x_sparse`, `y_sparse`, and `x_sparse * y_sparse`;
- pre-ReLU non-positive percentage and post-ReLU zero percentage;
- per-head activity and strongest last-token latent units;
- A-vs-B comparison and top-unit overlap;
- ReLU examples used by the learning challenge.

The core experiment is not a scripted animation. The UI summarizes tensors generated by the running model.

## Evidence label

`bdh_trained.pt` is an **independently trained toy BDH checkpoint** trained on Tiny Shakespeare with Pathway's public toy implementation. It is **not** an official Pathway production checkpoint.

Layer-1 measurements for this checkpoint:

| Input | x_sparse active |
|---|---:|
| `The king walked into the castle.` | 17.95% |
| `A A A A A A A A A A A A` | 20.29% |
| `xqz @@ 91827 zz qwe 66219` | 42.52% |
| `The scientist studied neural networks.` | 17.68% |

For the natural-language example, 82.05% of Layer-1 `x_latent` values are non-positive and 82.05% of `x_sparse` values are exactly zero. Natural-vs-repetition top-20 overlap is 20%; natural-vs-noise is 0%; natural-vs-technical is 100%. These are local measurements, not general BDH guarantees.

## Primary research (2022-2026)

1. Kosowski, A. et al. (2025), **The Dragon Hatchling: The Missing Link between the Transformer and Models of the Brain**. arXiv:2509.26507. https://arxiv.org/abs/2509.26507
2. Cunningham, H. et al. (2023), **Sparse Autoencoders Find Highly Interpretable Features in Language Models**. arXiv:2309.08600. https://arxiv.org/abs/2309.08600
3. Gao, L. et al. (2024), **Scaling and Evaluating Sparse Autoencoders**. arXiv:2406.04093. https://arxiv.org/abs/2406.04093
4. Engdahl, B. et al. (2026), **BDH-CQ: In-Context Learning with Recurrent Latent Reasoning**. arXiv:2608.09888. https://arxiv.org/abs/2608.09888

BDH-CQ is architectural-family context only; this artifact runs the public toy BDH architecture, not BDH-CQ.

## Limitations

- small byte-level toy model trained on Tiny Shakespeare;
- not directly comparable to Pathway's larger published systems;
- ReLU explains non-negativity and zeroing, not every reported BDH sparsity property;
- top-unit overlap is an educational diagnostic, not evidence of monosemanticity;
- deployment may have cold-start latency on a free hosting tier.
